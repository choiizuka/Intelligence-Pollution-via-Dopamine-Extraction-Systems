## 📜 2. 有害性の数理モデル (Mathematical Model)

社会的有害性 $Harm$ を以下の関数で定義する。

$$Harm = \sum_{i=1}^{n} (F_i \times L_{eff} \times A)$$

* $L_{eff}$: 1 投稿あたりの嘘・誇張・感情操作の効率（Lies Efficiency）。
* $A$: アルゴリズムによる増幅倍率（Amplification）。

**論理的結論**: $L_{eff}$ が 0 でない限り、$F$ の増大は社会的ノイズを指数関数的に増大させる。MIT の研究によれば、嘘は真実の 6.7 倍の速度で拡散されるため、$L_{eff} \gg \text{Truth}$ が常態化している。
